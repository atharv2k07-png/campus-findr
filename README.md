# 📍 Campus Findr — College Lost & Found System

A lightweight, responsive web application designed for college campuses to help students, faculty, and staff report, track, and recover misplaced belongings efficiently.

---

## 📌 Problem Statement
In large college environments, items such as student ID cards, keys, notebooks, and electronics are frequently misplaced. Relying on disorganized WhatsApp forwards or physical notice boards causes high friction, delayed recovery, and privacy concerns. **Campus Findr** provides a centralized, searchable campus board with direct claiming workflows.

---

## 🚀 Features
- **Report Lost/Found Items:** Simple form capturing item name, category, suspected location, date, contact details, and photo upload.
- **Dynamic Search & Filters:** Filter listings by status (`Lost`, `Found`, `Resolved/Claimed`), category, or campus location keywords.
- **Secure Verification & Claiming:** Claimers submit verification proof (e.g., ID number, lockscreen description) before handover.
- **Image Optimization:** Automated server-side image compression and resizing using Python Pillow (PIL).
- **Mobile-First Interface:** Responsive UI optimized for smartphone browsers.

---

## 🛠️ Tech Stack
- **Backend:** Python (Flask)
- **Database:** SQLite with SQLAlchemy ORM
- **Image Processing:** Pillow (PIL)
- **Frontend:** HTML5, Tailwind CSS, JavaScript (Fetch API)
